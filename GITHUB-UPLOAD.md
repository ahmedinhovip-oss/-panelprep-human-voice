# Upload this project to GitHub

1. Make the GitHub repository **Public**.
2. Open the repository's **Add file > Upload files** page.
3. Upload the **contents of this folder** (not the ZIP file itself). Preserve the folders such as `public/`, `server/`, `scripts/`, and `artifact/`.
4. Commit with a message such as `Initial public release of PanelPrep`.
5. Confirm that `README.md`, `LICENSE`, `package.json`, `public/`, and `server/` are visible in GitHub.
6. Never upload a real `.env` file. Only `.env.example` belongs in the repository.

After GitHub shows the files, return to the Claude for Open Source form and select this public repository.
