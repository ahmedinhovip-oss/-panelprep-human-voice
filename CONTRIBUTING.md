# Contributing to PanelPrep

Contributions are welcome.

1. Fork the repository and create a feature branch.
2. Run `npm install` and test locally in demo mode with `npm start`.
3. Keep API keys and credentials only in `.env`; never commit `.env`.
4. Run `npm run smoke` before opening a pull request.
5. Describe the problem, the change, and how you tested it in the pull request.

For larger changes, open an issue first so the approach can be discussed.
